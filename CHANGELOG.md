# Changelog

All notable changes specific to `saewoo's AutoDuty` are documented here.

## Unreleased

### Added

- Gearsetter-recommended item protection for Auto Desynth.
- Gearsetter safety flow for automatic Grand Company turn-ins.
  - Updates affected gearsets and restores the original gearset.
  - Moves remaining recommended upgrades into the matching Armoury Chest.
  - Requires AutoRetainer delivery mode: `Hide Armoury Chest Items`.
- Gearsetter mode for the gear update button.
  - Updates every gearset with a Gearsetter recommendation.
  - Restores the originally equipped gearset afterward.
- Search field for the preferred repair NPC selector.

### Changed

- Plugin display name: `saewoo's AutoDuty`.
- Plugin repository URL: `saewoo-dalamud/AutoDuty`.

## Upstream base

- Based on [erdelf/AutoDuty](https://github.com/erdelf/AutoDuty) `0.0.0.335`.
