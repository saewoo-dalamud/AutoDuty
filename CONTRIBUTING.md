# Contributing

## Scope

- Upstream source: [erdelf/AutoDuty](https://github.com/erdelf/AutoDuty).
- This repository: saewoo-specific customizations.
- General AutoDuty fixes: contribute upstream when applicable.

## Branches

- `master`: upstream mirror. No fork-specific commits.
- `main`: saewoo-specific changes and release source.

## Compatibility

- Plugin `InternalName`: `AutoDuty`.
- Keep the upstream major, minor, and build version components.
- Use a distinct revision number for fork releases.

## Validation

- Build `AutoDuty/AutoDuty.csproj` before submitting changes.
- Keep localization JSON valid.
